# Coding Agents Workshop II: Before You Arrive

Make sure you have all the software installed for the first workshop.

Additionally, you should already be able to:

- Use `claude` in a terminal, and have it logged in to a paid account
- Know what `CLAUDE.md` is and why it is important
- Know how to use `pixi` to install Python packages and what `pixi.lock` is for

If you have not done these things yet, consider attending the first workshop as
well.

# Vibe Sciencing Workshops

Teaching material for two hands-on workshops on coding agents (Claude Code), by
Luis Pedro Coelho. The workshops are given live: the instructor types, and the
room follows along on their own laptops.


| Workshop | Directory | Contents |
| -------- | --------- | -------- |
| 1        | [`1__intro/`](1__intro/) | **Coding Agents: an Introduction.** What a coding agent is, how to ask Claude for code, `CLAUDE.md` and `/init`, and what "context" is and how to manage it. |
| 2        | [`2__science/`](2__science/) | **Coding Agents for Science.** A longer case study: data analysis, plotting, iterating on an analysis, and checking what the agent actually did. Builds on part 1. *(In progress.)* |


Workshop 2 is a continuation of workshop 1, but if you are already familiar
with coding agents, you can skip workshop 1 and go straight to the second one.
You may also decide to only attend the first workshop and attend the second one
later, when it is offered again.

## Attending?

Read [`1__intro/pre-workshop-checklist.md`](1__intro/pre-workshop-checklist.md)
and do it **at least a day before**. In short: you need `git`, `pixi` and
`claude` working in a terminal. You need a **paid Claude account**: the free
version is not enough.

You need to be comfortable with the shell and basic git — the workshop does not
teach those.
